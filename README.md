# Login Page Customizer

Brand `wp-login.php` without touching code, a theme file, or a snippet plugin.

## Features

- **Custom logo** — image URL plus width/height, replacing the WordPress logo.
- **Colours** — page background, form background, button colour and button
  text colour.
- **Logo link & title** — point the logo at your home page (or any URL) and
  set its hover title.
- **Extra CSS** — a free-form box for anything else (`@import` and HTML tags
  are stripped for safety).
- **Error-box tweak** — optionally remove the box shadow from login
  error/notice boxes.

Everything applies to the login screen only — your theme and admin area are
untouched.

## Installation

1. Upload the plugin folder to `wp-content/plugins/`.
2. Activate it.
3. Brand away under Settings → Login Page.
